# Content

Knowledge base, glossary and audio manifest. **Owner: @itsya-ssine.**

```
content/
  knowledge_base/   Disease sheets, treatments, irrigation parameters (JSON/YAML)
  glossary/         Crop, disease, pest and product terms: FR, AR, Darija, Amazigh
  audio/            Audio manifest only (files are not committed; see data/README.md)
```

Rules:
- Every advice entry needs an agronomist sign-off flag before it can be published.
- Chemicals must be on the ONSSA-approved list, with dose, pre-harvest interval and safety notes.
- Prefer curated templates over free-form generation.
